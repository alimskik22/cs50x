# Problem Set 2

This problem set introduces arrays, string manipulation, command-line arguments, and cryptography fundamentals.

## Problems

| Problem | Difficulty | Description |
|---------|-----------|-------------|
| [Scrabble](/pset2/scrabble/) | Warmup | Compute which word scores higher in Scrabble (letter values) |
| [Readability](/pset2/readability/) | Less | Compute the grade level of text using the Coleman-Liau index |
| [Caesar](/pset2/caesar/) | Less | Encrypt text using Caesar's cipher (shift letters by a key) |
| [Substitution](/pset2/substitution/) | More | Encrypt text using a substitution cipher (map letters via key) |

## What I Learned

- **Arrays**: Storing and indexing sequences of characters
- **Strings**: String as arrays of `char`, `string.h` functions (`strlen`, `strcmp`, etc.)
- **Command-line arguments**: `argc` and `argv` for program inputs
- **Character manipulation**: `isalpha`, `isupper`, `islower`, `toupper`, `tolower`
- **Algorithms**: Caesar cipher, substitution cipher, Coleman-Liau index
- **Loops & Conditionals**: Nested loops for encryption, bounds checking
