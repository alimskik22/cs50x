# Problem Set 7

This problem set introduces SQL (Structured Query Language) for querying and manipulating relational databases.

## Problems

| Problem | Difficulty | Description |
|---------|-----------|-------------|
| [Songs](/pset7/songs/) | Practice | Write SQL queries to analyze a Spotify-like database of songs |
| [Movies](/pset7/movies/) | Less / More | Write SQL queries to answer questions about a movie database (IMDb-style) |
| [Fiftyville](/pset7/fiftyville/) | Practice | Solve a mystery using SQL to investigate a theft in the town of Fiftyville |

## What I Learned

- **SQL syntax**: `SELECT`, `FROM`, `WHERE`, `JOIN`, `GROUP BY`, `ORDER BY`, `LIMIT`
- **Filtering**: `=`, `LIKE`, `IN`, `BETWEEN`, `AND`, `OR`, `NOT`
- **Aggregation**: `COUNT()`, `AVG()`, `SUM()`, `MAX()`, `MIN()`
- **Joining tables**: `INNER JOIN`, `LEFT JOIN`, multiple `JOIN` clauses
- **Subqueries**: Nesting `SELECT` statements inside `WHERE` or `FROM`
- **Pattern matching**: `LIKE '%pattern%'` for partial string matches
- **Sorting & limiting**: `ORDER BY` (ASC/DESC), `LIMIT`, `OFFSET`
- **Logical deduction**: Combining multiple clues to solve Fiftyville mystery
