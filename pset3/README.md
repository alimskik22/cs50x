# Problem Set 3

This problem set introduces sorting algorithms, voting systems, and recursive problem-solving.

## Problems

| Problem | Difficulty | Description |
|---------|-----------|-------------|
| [Sort](/pset3/sort/) | Practice | Analyze and compare sorting algorithms (bubble sort, selection sort, merge sort) |
| [Plurality](/pset3/plurality/) | Practice | Simulate a plurality vote election (candidate with most votes wins) |
| [Runoff](/pset3/runoff/) | Less | Simulate a ranked-choice voting system (instant runoff) |

## What I Learned

- **Sorting algorithms**: Bubble sort, selection sort, merge sort (time complexity analysis)
- **Voting algorithms**: Plurality vs. runoff (ranked-choice) voting
- **Arrays & structs**: Organizing candidate data with `typedef struct`
- **Searching & counting**: Finding winners, eliminating candidates, redistributing votes
- **Recursive thinking**: Tabulating preferences in runoff elections
- **Algorithm efficiency**: Comparing O(n²) vs O(n log n) sorting
