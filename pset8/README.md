# Problem Set 8

This problem set introduces web development fundamentals: HTML for structure, CSS for styling, and JavaScript for interactivity.

## Problems

| Problem | Difficulty | Description |
|---------|-----------|-------------|
| [Trivia](/pset8/trivia/) | Practice | Build a quiz webpage with multiple-choice and free-response questions using JavaScript |
| [Homepage](/pset8/homepage/) | Practice | Design a personal homepage with at least 4 pages, Bootstrap, and interactive features |

## What I Learned

- **HTML5**: Semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`)
- **CSS3**: Selectors, properties, flexbox, grid, responsive design
- **JavaScript**: DOM manipulation, event listeners, form validation, dynamic content
- **Bootstrap**: Responsive grid system, components, utility classes
- **GitHub Pages**: Deploying static websites for free
- **Forms**: Input handling, radio buttons, text fields, submission events
- **Local storage**: Saving user data in the browser
