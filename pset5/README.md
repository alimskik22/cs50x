# Problem Set 5

This problem set introduces pointers, memory allocation, and efficient data structures for storing and retrieving information.

## Problems

| Problem | Difficulty | Description |
|---------|-----------|-------------|
| [Inheritance](/pset5/inheritance/) | Practice | Simulate genetic inheritance using recursive memory allocation |
| [Speller](/pset5/speller/) | Less / More | Implement a spell-checker using a hash table (or trie) for dictionary lookup |

## What I Learned

- **Dynamic memory allocation**: `malloc`, `calloc`, `free`
- **Pointers to pointers**: Building recursive data structures
- **Structs & linked lists**: Creating nodes with `typedef struct`
- **Hash tables**: Fast O(1) average lookup time
- **Hash functions**: Converting strings to integer indices
- **Tries** (if implemented): Tree-based string storage with O(1) lookups
- **Memory management**: Avoiding leaks with proper `free()` usage
- **Recursion**: Building family trees in Inheritance
