# Problem Set 9

This problem set introduces web application development using Flask, a Python web framework, along with databases, sessions, and user authentication.

## Problems

| Problem | Difficulty | Description |
|---------|-----------|-------------|
| [Birthdays](/pset9/birthdays/) | Practice | Create a web app to store and display friends' birthdays using SQLite and Flask |
| [Finance](/pset9/finance/) | Practice | Build a stock trading web app where users can buy and sell stocks (IEX Cloud API) |

## What I Learned

- **Flask**: Routes, templates, request handling, sessions
- **Jinja**: Template inheritance, conditionals, loops, variables
- **SQLite**: Database integration with Flask (`sqlite3` module)
- **CSRF protection**: Using `POST` vs `GET` appropriately
- **Session management**: Login/logout, user-specific data
- **API integration**: Fetching live stock prices from IEX Cloud
- **Password security**: Hashing with `werkzeug.security` (`generate_password_hash`, `check_password_hash`)
- **Form handling**: `request.form.get()`, validation, error messages
- **HTML/CSS**: Bootstrap integration, responsive tables
